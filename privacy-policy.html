Privacy Policy – Locked-In Studio

Last updated: November 2026

Who we are

Locked-In Studio is a private software tool operated by the owner of the YouTube channel LOCKED IN. Contact: DEINE-KANAL-GMAIL

YouTube API Services

Locked-In Studio uses YouTube API Services. By using it you are bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What the tool does

Locked-In Studio runs locally on the owner's computer. It uses the YouTube Data API to upload videos, set thumbnails and titles and add videos to playlists, and the YouTube Analytics and Reporting APIs to read statistics – for the owner's own YouTube channel only.

Data we access, collect and use

When the channel owner signs in with Google, the tool requests access to upload and manage videos on the owner's own channel (youtube.upload, youtube) and to read the owner's own channel statistics (yt-analytics.readonly). It uses this only to publish the owner's videos and to evaluate which of the owner's videos perform well. We do not access, collect or store data of any other users or viewers; statistics are aggregated and refer to our own channel only.

How data is stored and shared

Access tokens are stored only in the macOS Keychain on the owner's computer. Channel statistics and the IDs of our own uploaded videos are stored only in a local database on that computer. Nothing is sold, shared with third parties or used for advertising. No cookies or tracking are used on this website.

Data retention and deletion

  • Statistics are refreshed daily and kept only as long as the tool is authorized for the channel.
  • Access can be revoked at any time in the Google security settings (https://myaccount.google.com/permissions). After revocation the tool can no longer access any data.
  • All locally stored API data is deleted within 30 days after revocation, or immediately on request by deleting the tool's data folder.
  • Deletion requests can be sent to winter420arc@gmail.com and are handled within 7 days.

Changes

We may update this policy. The current version is always published on this page.
