Privacy Policy – Locked-In Studio

Last updated: November 2026

Who we are

Locked-In Studio is a private software tool operated by the owner of the YouTube channel LOCKED IN. Contact: DEINE-KANAL-GMAIL

What the tool does

Locked-In Studio runs locally on the owner's computer. It uses the YouTube API Services to upload videos, set thumbnails and titles, manage playlists and read channel statistics (YouTube Analytics) for the owner's own YouTube channel only.

Data we access

When the channel owner signs in with Google, the tool requests access to upload and manage videos on the owner's own channel (youtube.upload, youtube) and to read the owner's own channel statistics (yt-analytics.readonly). We do not access, collect or store data of any other users or viewers. Statistics are only read in aggregated form for our own channel.

How data is stored

Access tokens and channel statistics are stored only locally on the owner's computer (access tokens in the macOS Keychain). Nothing is sold, shared with third parties or used for advertising.

Third-party services

This tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time via the Google security settings. Locally stored data can be deleted by removing the tool's data folder.

Changes

We may update this policy. The current version is always published on this page.
